## Other FOSS Projects

A selection of other free open-source software (FOSS) projects created by the developer that may be
of interest.

- [ClearNet ](https://github.com/ASPTechInc/ClearNet) - A Dart-based parental control application
  that blocks harmful website content, restricts applications and prevents unauthorised application
  removal. It uses the Flutter framework.

- [Daymark](https://github.com/ASPTechInc/Daymark) - A privacy-focused day counter for Android
  written in Kotlin that tracks the number of days since or until a specific event for
  monitoring purposes.

- [GoodBudget](https://github.com/ASPTechInc/GoodBudget) - A cross-platform application that serves
  as a budget monitor and expense tracker.  
  It persists data to a Hive NoSQL database and was built using the Flutter framework and written 
  in Dart for Android and iOS platforms.

- [iCare](https://github.com/ASPTechInc/iCare) - An open-source hospital management website written
  in Python.

- [Lexivo](https://github.com/ASPTechInc/Lexivo) – _This repository (included for reference)_

  A cross-platform word puzzle game built with
  Rust and [egui/eframe](https://github.com/emilk/egui/) that challenges players to solve linguistic
  puzzles by transforming words through single-letter, double-letter or triple-letter changes and
  anagrams.

  *GitHub page*: https://asptechinc.github.io/Lexivo

- [LITUK_quiz](https://github.com/ASPTechInc/LITUK_quiz) - The Life in the United Kingdom (LITUK)
  quiz application prepares applicants for the LITUK test which is a requirement for the Indefinite
  Leave to Remain (ILR) in the United Kingdom (UK) or for British citizenship. It was built using
  the Flutter framework and written in Dart.

- [NovaDesign-app](https://github.com/ASPTechInc/NovaDesign-app) - An Java application that allows
  users to create and share designs for their homes.

- [ResuVue](https://github.com/ASPTechInc/ResuVue) - A smart, simple resume builder powered by
  modern web technology

- [Rhythmo](https://github.com/ASPTechInc/Rhythmo) - A tool built using Go to help users track their
  daily habits, either via the command line or a web interface and synchronise data between both.

- [SolesMates](https://github.com/ASPTechInc/SolesMates) - A Dart application that provides
  comfortable footwear at a great value. It uses the Flutter framework.

- [SteerWise](https://github.com/ASPTechInc/SteerWise) - A smart, voice-guided Flutter app that
  helps new drivers practise turning, roundabouts and more with camera and road simulation.

- [YumMealPrep](https://github.com/ASPTechInc/YumMealPrep) - A daily, weekly and monthly meal
  planning application as well as a receipt book app
